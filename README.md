# عصب تك | ASAB TECH

> **Business Prototype · Saudi Arabia · AI & Automation**

موقع تعريفي تجريبي احترافي لشركة **عصب تك | ASAB TECH** (اسم وهوية مقترحان)، وهي شركة تستهدف تقديم حلول الذكاء الاصطناعي والأتمتة والتكامل البرمجي للشركات، مع تركيز أولي على **الدمام والخبر بالمملكة العربية السعودية**. أُعدّ هذا النموذج لعرض الفكرة ومناقشتها مع الأستاذ عبد المجيد، ولم يعتمد بصفته موقعاً تجارياً رسمياً.

## المستودع المقترح

- **Repository name:** `asab-tech-ai-automation-website`
- **GitHub description:** `Responsive Arabic RTL prototype for ASAB TECH, a Saudi AI and business automation company. Single-file HTML/CSS/JS with services, packages, chatbot demo and ROI calculator.`
- **Website title:** `عصب تك | ASAB TECH — حلول الذكاء الاصطناعي والأتمتة`
- **Primary market:** Dammam & Khobar, Saudi Arabia
- **Status:** Prototype / Branding and pricing pending approval

## التقنيات

- **HTML5** منظّم ودلالي (Semantic).
- **CSS3** داخلي، يدعم **RTL** والعرض المتجاوب، والسمات الفاتحة/الداكنة.
- **Vanilla JavaScript** داخلي بالكامل، دون إطار عمل أو مكتبات خارجية.
- **Inline SVG** للشعار والأيقونات ومخطط الأتمتة.
- لا توجد طلبات شبكة من الصفحة في نسختها الحالية؛ يعمل النموذج محلياً.

## المزايا

1. هوية بصرية مقترحة: كحلي عميق، تركواز تقني، وأزرق/بنفسجي.
2. شعار SVG مدمج مستوحى من فكرة الأعصاب والتكامل بين نقاط البيانات.
3. صفحة عربية متجاوبة للأجهزة المكتبية والمحمولة باتجاه RTL.
4. أقسام الخدمات: مساعدو العملاء، أتمتة الإجراءات، تكامل API، المساعد المعرفي، لوحات البيانات، CRM، التجارة الإلكترونية، معالجة المستندات، وتطوير الأنظمة.
5. تصور لمنهجية العمل والقطاعات المستهدفة.
6. ثلاث باقات استرشادية بالريال السعودي مع توضيح رسوم الإعداد والدعم.
7. محاكاة محادثة تفاعلية بقواعد ثابتة **وليست نموذج ذكاء اصطناعي فعلياً**.
8. حاسبة تقريبية لساعات العمل المحتمل توفيرها مع توضيح المعادلة والافتراضات.
9. أسئلة شائعة قابلة للفتح، وواجهة وضع داكن/فاتح، وقائمة جوال.
10. نموذج طلب استشارة **محلي فقط**: يسمح بنسخ ملخص الطلب أو تنزيله TXT، دون ادعاء إرسال بيانات أو تخزينها في خادم.
11. تحسينات وصول: تباين واضح، مسار تخطي المحتوى، حالات تركيز، `aria`، واحترام تقليل الحركة.

## إجراء التعديلات السريعة

1. **اسم الشركة والشعار:** ابحث في `index.html` عن `عصب تك` و`ASAB TECH`، وعدّل نصوص العلامة ووسم `<title>` و`description`. الشعار موجود كـ SVG داخل عناصر `.brand-mark`، والأيقونة في `<link rel="icon">`.
2. **الألوان:** عدّل متغيرات CSS داخل `:root` وكذلك `html[data-theme="light"]`.
3. **الخدمات:** عدّل البطاقات ضمن `<section id="services">`.
4. **الباقات والأسعار:** عدّل `<section id="pricing">`، وحدث أيضاً جدول الباقات في هذا الملف، والإجابات التجريبية في متغير JavaScript `answers`.
5. **القطاعات:** عدّل محتويات `<section id="use-cases">`.
6. **التواصل الحقيقي:** النموذج الحالي لا يرسل البيانات. لإضافة قناة إرسال يجب ربطه بخلفية آمنة (Backend) ونقطة API موثقة، أو بموفر نماذج موثوق، وإضافة سياسة خصوصية/موافقة مناسبة قبل جمع البيانات. لا تضع مفاتيح خدمات أو رموز وصول في JavaScript الموجود في المتصفح.
7. **الموقع الرسمي:** بعد اعتماد الاسم التجاري والشعار والبيانات النظامية، حدّث عبارات «النموذج التجريبي»، وأضف معلومات التواصل الفعلية والصفحات النظامية المناسبة.

## نشر الموقع على GitHub Pages

1. أنشئ مستودع GitHub عاماً بالاسم المقترح.
2. ارفع الملفين `index.html` و`README.md` إلى الفرع `main` في جذر المستودع.
3. افتح **Settings → Pages** في المستودع.
4. اختر **Deploy from a branch → main → /(root)** ثم **Save**.
5. انتظر اكتمال عملية النشر، واستخدم الرابط الذي تعرضه GitHub Pages داخل إعدادات المستودع.

> GitHub Pages مناسب لعرض نموذج ثابت. لا تستخدمه وحده لمعالجة بيانات العملاء أو مفاتيح API السرية أو التكاملات الحساسة.

## ملاحظات أمنية وتشغيلية مهمة

- النموذج لا يجري مكالمات إلى OpenAI أو WhatsApp أو CRM؛ هذه كلها **خدمات مقترحة وليست متصلة**.
- المحادثة التوضيحية تعتمد على ردود ثابتة، وليست مساعداً معرفياً حقيقياً.
- حاسبة الوقت تعتمد على افتراضات يدخلها الزائر؛ ليست نتيجة تنفيذ أو دراسة واقعية.
- يجب فحص توافر API والصلاحيات والاعتمادية والتكاليف لكل عميل قبل التعاقد.
- في السوق السعودي، يتطلب التعامل مع البيانات الشخصية مراعاة **نظام حماية البيانات الشخصية (PDPL)** ولوائحه، بما فيها متطلبات الإفصاح ونقل البيانات خارج المملكة، وتقييم دور كل جهة ومزودي الخدمات. لا يعني عرض هذه المبادئ أن الموقع أو الشركة حاصلة على اعتماد امتثال.
- لا تستخدم هذا التصور لادعاء عملاء أو إنجازات أو شهادات اعتماد لم تتحقق بعد.

مرجع تنظيمي عام: [الدليل الرسمي لهيئة البيانات والذكاء الاصطناعي السعودية بشأن PDPL](https://dgp.sdaia.gov.sa/wps/portal/pdp/knowledgecenter/details/PDPLCP/).
