# عصب سوفت | ASAB SOFT — Interactive Company Showcase

**Website prototype · Saudi Arabia · Single-file HTML/CSS/Vanilla JS · Arabic & English**

نسخة تطويرية جديدة من النموذج التعريفي لعصب سوفت (ASAB SOFT)، مع تصميم Hero تفاعلي أصلي يمثل ربط مجالات الخدمات بمنصة ذكاء مركزية، وكتالوج يشمل **48 منتجاً وخدمة في 8 مجالات**، و**6 باقات تجارية استرشادية** مأخوذة من كتالوج المنتجات بتاريخ 2026-11-01.

> **الحالة:** نموذج تسويقي وتجريبي، وليس إعلاناً عن ترخيص تجاري أو إطلاق رسمي أو تكاملات خلفية جاهزة. الاسم والهوية والتسعير بانتظار اعتماد المؤسس.

## Live source / المستودع

Repository: `Eng-Hasan-Hajjar/asab-tech-ai-automation-website`

Website file: `index.html`

## التشغيل

1. ضع `index.html` داخل مجلد المشروع.
2. افتحه مباشرة في متصفح حديث. **لا تحتاج إلى Laravel أو Node.js أو خادم أو قاعدة بيانات**.
3. يمكنك نشره على GitHub Pages من `Settings → Pages → Deploy from a branch → main → /(root)`.

*ملاحظة الخطوط:* يتم تحميل خط Alexandria للعناوين وIBM Plex Sans Arabic للنصوص العربية وInter للإنجليزية من Google Fonts عند توافر الإنترنت. عند انقطاع الاتصال تُستخدم خطوط النظام الاحتياطية. لا توجد ملفات خطوط ضمن المشروع.

## ما الجديد؟

- Hero داكن ومتحرك مع مدارات وعُقد لـ8 مجالات. الضغط على أي عقدة ينقل الزائر إلى منتجات المجال.
- تصميم متجاوب للكمبيوتر واللوحي والجوال، مع مراعاة تخفيض الحركة `prefers-reduced-motion`.
- كتالوج **48 منتجاً** كامل التفاصيل، ويمكن البحث بالعربية والإنجليزية وبمعرّف المنتج والتصنيف والتسعير.
- فلاتر تصنيفات وترتيب سعري / أبجدي، وعرض 9 منتجات أولاً ثم إظهار الباقي.
- بطاقات تفاصيل تحتوي السعر المقترح ومدة التنفيذ والجاهزية والدعم، مع اختيار المنتج لطلب استشارة.
- **6 باقات**: الانطلاقة الرقمية، المطعم السريع، عميلك أولاً، أعمال مؤتمتة، المساعد الذكي، العقار الذكي.
- ترجمة فعلية للمحتوى والتصنيفات وأسماء المنتجات والوصف والباقات، مع التبديل بين **العربية RTL والإنجليزية LTR**.
- نموذج محلي يصدر ملخصاً في الحافظة أو TXT؛ **لا يرسل طلبات لخادم** ولا يخزن بيانات العملاء على الإنترنت.
- أقسام القطاعات والمنهجية والأسئلة الشائعة والتواصل.

## تحديث المنتجات والأسعار

داخل `index.html` ستجد متغير `CATALOG` في JavaScript. تحتوي مصفوفة `products` على المنتجات، ومنها:

| حقل | معناه |
|---|---|
| `id` | معرّف المنتج AS-001 ... AS-048 |
| `category` / `cat_en` | التصنيف بالعربية والإنجليزية |
| `title` / `name_en` | الاسم باللغتين |
| `value` / `desc_en` | وصف الخدمة باللغتين |
| `price_min_sar` / `price_max_sar` | حدود السعر المقترح بالريال السعودي |
| `delivery_estimate` | المدة المبدئية |
| `readiness` | هل الخدمة قابلة للبيع حالياً أم تتطلب تخصيصاً أو مراجعة؟ |
| `support_monthly_estimate_sar` | قيمة دعم شهري استرشادية عندما تكون محددة |
| `caveat` | شرط أو قيد مهم ينبغي ذكره للعميل |

الباقات ضمن `CATALOG.packages`. في المنتجات التي يتحدد سعرها حسب العقد، القيمة `0` لحدي السعر تُعرض للزائر كـ«حسب الاتفاق / On request».

للتعديل على النصوص العامة في الموقع، استخدم قاموس `I18N` الذي يحتوي `ar` و`en`. ولتغيير الألوان، استخدم متغيرات CSS ضمن `:root`.

## إرشادات التخصيص قبل الإطلاق

- اعتماد الاسم القانوني والاسم التجاري والشعار والألوان مع الأستاذ عبد المجيد.
- التأكد من حقيقة نطاق كل منتج وقابليته للتسليم والمدة والأتعاب قبل طرحه تجارياً.
- مراجعة الضرائب والتسعير وتكاليف الرسائل ومنصات النماذج والاستضافة.
- إضافة معلومات التواصل الرسمية والرخصة والصفحات القانونية عند توفرها.
- استخدام Backend آمن لاستقبال طلبات الزوار أو ربط WhatsApp Business API وCRM ومساعد AI فعلي. **لا تضع أي سر أو API Key ضمن JavaScript الظاهر للزوار.**
- دراسة متطلبات نظام حماية البيانات الشخصية السعودي (PDPL) واتفاقيات معالجة البيانات ونقلها قبل معالجة بيانات فعلية للعملاء.

## حدود هذه النسخة

الصفحة **Static Frontend**. لا تتصل بـ OpenAI أو WhatsApp أو CRM فعلي، ولا تنفذ حجزاً أو دفعة أو عملية تكامل. التفاعل الموجود هو فرز البيانات وعرضها وتحضير ملخص طلب محلي. الأسعار والأزمنة مقترحات أولية للتفاوض، **ليست عروض أسعار ملزمة** ولا تشمل الأطراف الثالثة أو الضرائب.

## الاختبارات المنفذة

- فحص JavaScript باستخدام `node --check`.
- فحص متصفح محلي عبر تشغيل محتوى الصفحة واختبار عرض 9 منتجات، وإظهار 48، والبحث والتبديل للإنجليزية، ونافذة التفاصيل، ونقل اختيار المنتج إلى نموذج الاستشارة.
- فحص تجاوب أحجام **320px, 390px, 768px, 1440px** بلا تمرير أفقي في الصفحة.
- تم تعطيل تنزيل Google Fonts أثناء لقطات الاختبار الآلي لضمان اختبار الصفحة بدون اعتماد على الشبكة. يلزم فحص يدوي إضافي على أجهزة فعلية قبل النشر التجاري.
